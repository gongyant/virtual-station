# P6C 原口径气象驱动验证

通过官方CDS ERA5-Land hourly time-series接口下载16个紧凑区域包，共154,354,196字节。仅请求2m temperature和total precipitation，日期2015-01-01至2021-01-01，覆盖177个实际所需格点；请求矩形含333个格点，不是单点流域替代。官方下载回执、job ID、MD5、SHA256和NetCDF原始成员均保存于driver。

使用P6B冻结官方A全上游几何、原格点及交叠面积整数截断归一权重。ARCO降水已经反累计，绝不再次差分；降水时间戳减1h。小时流域加权后P取0.01mm、T取0.1°C；日P求和取0.01mm、T平均取0.1°C；月累计P、按完整日平均T。每年2020有366天×24小时。2019最终小时仅在历史重叠验证按原脚本填补规则复现，2020边界使用真实2021-01-01 00UTC。2020-01前月P来自已冻结原2019-12。

先验证ID2、377、533、171共4个代表站；全部通过后才处理其余站。全24站共1440个历史站月，实际通过1440；门槛未改：每月P绝对差≤0.18mm、T绝对差≤0.052°C，P≥36mm时相对差≤0.005。最大月P差0.17000000mm，最大月T差0.01071429°C。详情见driver/ALL24_HISTORICAL_PARITY.csv。数值容差通过表示按P6B契约一致，不能声称逐位完全相同。
