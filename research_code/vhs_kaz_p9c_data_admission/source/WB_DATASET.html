Coverage & Extent
Geographical Coverage
Kazakhstan, Kyrgyz Republic, Tajikistan, Turkmenistan, Uzbekistan
Geographical Description
The data include gauge stations from the five Central Asian Countries (which includes Kazakhstan, Kyrgyz Republic, Tajikistan, Turkmenistan and Uzbekistan).
