## 4. 三个必须由老师确认的科研问题

1. **单位**：discharge_syr_darya_monthly_all.csv 的月 Q 是否 m³/s？年径流交叉核对支持该假设但未确认；met 的 p / t 单位；KZDAM KC/KD/KS/KU 的单位与物理含义。
2. **控制体**：reach268_water_balance.csv 的残余符号约定（源文件为 dW − P_vol + ET_vol − W引水，标准平衡为 dW + P_vol − ET_vol − W引水），需要控制体定义与正方向。
3. **河段**：16037 → 16039 是否为 268 km 河段的上下游控制断面？断面几何从哪里取得？
