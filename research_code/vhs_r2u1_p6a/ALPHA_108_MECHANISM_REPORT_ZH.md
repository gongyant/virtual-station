# 108个alpha和折内标准化机制

108=27站×2模型×V1/V2两版本，仅54个V2是当前正式保存模型。108个selected_alpha全部100，确实是冻结网格[0.01,0.1,1,10,100]的上边界。

只读复算每个模型保存的nested_CV记录：104个best_alpha=10，4个best_alpha=100；按最优平均年度损失加该最优候选的标准误构造cutoff，再在容许集合中选最大alpha，108个选择均与原记录一致。100相对最小CV损失的最大增加约6.167%，都在one-SE范围内。程序没有把100硬写成模型输出，也没有证据表明气象项全被归零。

数学目标是||y−训练月均Q−Zβ||² + α||β||²；Z按同月训练资料中心化、ddof=1标准化；不惩罚月截距。增强矩阵SVD求解，未把alpha误当成标准差；也没有采用按样本数归一化后的另一套alpha定义。对每个模型，从train_ids和冻结气象重建mu/sd，最大误差0；月内Z均值最大绝对值4.63e-15。系数单位为每标准差m³/s，原始P/T/L1单位下斜率按beta/sd逐月记录。

Z'Z特征值给出的岭收缩因子λ/(λ+100)在本批模型所有方向约为0.708–0.857，不是“alpha=100就等于没学气象”。共同选择100来自本轮固定有限网格、平坦CV损失和one-SE偏好强收缩的组合；在上边界不能推出100是连续参数空间的最优值，也不能据此看旧测试分数扩展网格。

本轮没有运行新的CV、没有求解替代beta、没有扩大候选网格、没有重训。完整108行证据在diagnostics/ALPHA_108_MODEL_AUDIT.csv，逐月系数和标准化尺度在COEFFICIENT_SCALE_BY_MONTH.csv。
