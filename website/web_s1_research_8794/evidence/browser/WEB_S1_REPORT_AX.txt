# P6D：2018–2020固定模型失效机制诊断

本轮是看过P6B/P6C成绩后的后验描述性诊断，不是新的预注册确认性检验，不新增真实训练或预测成绩。研究任务仍为观测气象驱动的月末历史重建，不是提前一个月预报。范围为原24个奥地利站、864个真实配对站月、1728条既有预测；只加载48个原P4-V2模型，fit_calls=0，模型/alpha/区间参数不变。

## 1. 增量是否持续

- 2018：18/24站正技能，站点等权平均6.67%，中位数5.75%；L1绝对负NSE站数5。
- 2019：19/24站正技能，站点等权平均8.02%，中位数9.21%；L1绝对负NSE站数4。
- 2020：21/24站正技能，站点等权平均14.93%，中位数16.60%；L1绝对负NSE站数8。
- 2018_2019：19/24站正技能，站点等权平均7.35%，中位数7.62%；L1绝对负NSE站数2。
- 2018_2020：21/24站正技能，站点等权平均9.46%，中位数9.86%；L1绝对负NSE站数1。

2020失去增益站为171, 185, 545；36个月合并负技能站为185, 512, 545，合并负NSE只剩ID343。合并后的较好NSE不能消除2020单年/冬季失败：跨年均值差使合并SST变化，本报告从36条原记录重算，绝不平均年度NSE。ID171从2018–2019的+27.97%转为2020的−15.21%；ID455则由−11.92%转为+56.76%。相关站点和三年并非独立统计重复，没有总体显著性或跨流域普适结论。

## 2. 哪些月份造成主要损失

2020各站L1最坏单月占全年SSE的中位数为40.35%，前三个月占比中位数75.08%。先按每站全年SSE归一化、再站点等权汇总，最集中的三个日历月为5月(19.87%), 2月(13.90%), 6月(12.19%)。不能直接混合不同流域m³/s平方误差。

- ID171：全年L1 NSE -0.1980，相对技能-15.21%；最大误差月2020-03占全年SSE 47.49%，前三月占71.78%；最大增量损害月2020-03。
- ID185：全年L1 NSE 0.1115，相对技能-6.41%；最大误差月2020-02占全年SSE 23.13%，前三月占59.28%；最大增量损害月2020-03。
- ID255：全年L1 NSE -2.0682，相对技能20.73%；最大误差月2020-05占全年SSE 62.93%，前三月占90.32%；最大增量损害月2020-02。
- ID343：全年L1 NSE -1.4694，相对技能12.39%；最大误差月2020-05占全年SSE 29.45%，前三月占65.79%；最大增量损害月2020-03。
- ID383：全年L1 NSE -0.0907，相对技能17.85%；最大误差月2020-09占全年SSE 25.98%，前三月占58.22%；最大增量损害月2020-03。
- ID455：全年L1 NSE 0.7553，相对技能56.76%；最大误差月2020-03占全年SSE 43.30%，前三月占77.28%；最大增量损害月2020-11。
- ID533：全年L1 NSE 0.9446，相对技能2.88%；最大误差月2020-09占全年SSE 24.56%，前三月占70.58%；最大增量损害月2020-05。
- ID545：全年L1 NSE 0.8246，相对技能-3.31%；最大误差月2020-04占全年SSE 51.48%，前三月占74.47%；最大增量损害月2020-05。

ID171在2020-03的Qobs为1.7674、C0+PT为3.2380、L1为4.0138 m³/s；L1变化0.7758，当月平方误差改善量-2.8838（负值表示变坏），该月占L1全年SSE 47.49%。这是定位损失的数值事实，不是事件机制证明。

## 3. 为什么ID455、171反转

固定定义e=C0+PT−Qobs、d=L1−C0+PT，则逐月改善恒等于e²−(e+d)²=−2ed−d²。前项量化改变量与基线误差是否对准，后一项是改变量平方的代价，二者按同一月份平均。这里的代价是误差恒等式中的预测差平方，不是Ridge训练正则罚项。

- ID455 2018_2019：MSE改善 = 0.013795 − 0.047192 = -0.033397；技能-11.92%。
- ID455 2020：MSE改善 = 0.159236 − 0.046175 = 0.113061；技能56.76%。
- ID171 2018_2019：MSE改善 = 0.354375 − 0.136754 = 0.217621；技能27.97%。
- ID171 2020：MSE改善 = 0.031633 − 0.148539 = -0.116906；技能-15.21%。

ID455的改变量平方代价在两时期接近，但对准基线误差的收益从0.013795增加到0.159236，因而转正；ID171对准收益从0.354375降至0.031633，而代价仍约0.15，因而转负。此结论无需改变模型即可由配对误差恒等式验证，不能据此断言水库、积雪或调度改变。

## 4. 冻结模型真实贡献

全部模型使用保存的12月climate及按月mu/sd，常数特征按原规则z=0；raw预测=climate+beta_P×zP+beta_T×zT（L1另加beta_L1×zL1）。本轮最大重构绝对误差7.11e-15 m³/s。贡献单位为m³/s，beta本身在标准化空间；P6D_PREDICTION_DECOMPOSITION.csv另列每月原始单位有效斜率，不能把标准化系数直接当物理响应。

两模型差异必须包含前月P项、当月P/T项差和季节项差；同一固定变换下加法值明确，但相关变量的物理因果贡献并不唯一，未生成SHAP、未把回归项当作真实水文通量。

- ID455：前月P项RMS 0.2159 m³/s，总预测差RMS 0.2149 m³/s；当月P/T项差值RMS分别0.0176/0.0054 m³/s；季节项差为0.0000。
- ID171：前月P项RMS 0.3844 m³/s，总预测差RMS 0.3854 m³/s；当月P/T项差值RMS分别0.0045/0.0056 m³/s；季节项差为0.0000。

2020前月P项的平均绝对值除以本站训练Q标准差，24站中位数0.1743，范围0.0411–0.2894；这表示幅度，不代表独立解释率。

- ID533：预测与季节模板相关0.9975；气象总修正RMS 1.8864 m³/s，季节模板标准差18.0407 m³/s；前月P项平均绝对贡献0.7711 m³/s。
- ID545：预测与季节模板相关0.9899；气象总修正RMS 0.4442 m³/s，季节模板标准差2.6697 m³/s；前月P项平均绝对贡献0.2091 m³/s。
- ID171：预测与季节模板相关0.4188；气象总修正RMS 0.9312 m³/s，季节模板标准差0.6065 m³/s；前月P项平均绝对贡献0.3204 m³/s。
- ID455：预测与季节模板相关0.1920；气象总修正RMS 0.4669 m³/s，季节模板标准差0.1333 m³/s；前月P项平均绝对贡献0.1843 m³/s。

季节模板每年重复、气象项为有限幅度的异常修正，因此某些年度曲线相似。高相关本身不证明失败：ID533全年NSE很高但冬季失败；相同季节背景下小的校正方向差也能改变MSE。P6D_TEMPLATE_AND_PEAK_DIAGNOSTICS.csv保留每站逐年观测/预测峰值月份和幅度、异常相关性及模板MSE，未以高分筛选展示站点。

## 5. 冬季失效与分布漂移

2020 DJF共有6站同时相对/绝对失败，9站仅相对失败，3站虽相对改善但绝对NSE失败。DJF指该年1、2、12月，不是连续水文冬季；MAY_JUNE只有两个月。

- ID533：L1技能55.39%，NSE -9.0432；RMSE 1.1063 m³/s，对应观测标准差仅0.3491 m³/s；平均误差0.8086 m³/s，偏差平方占MSE 53.42%；幅度状态OVER_VARIABLE。
- ID545：L1技能34.44%，NSE -7.4079；RMSE 0.5490 m³/s，对应观测标准差仅0.1893 m³/s；平均误差-0.2236 m³/s，偏差平方占MSE 16.59%；幅度状态OVER_VARIABLE。
- ID383：L1技能-162.02%，NSE 0.3842；RMSE 0.5966 m³/s，对应观测标准差仅0.7603 m³/s；平均误差-0.3925 m³/s，偏差平方占MSE 43.28%；幅度状态UNDER_VARIABLE。
- ID2：L1技能-137.06%，NSE -1.0363；RMSE 0.5561 m³/s，对应观测标准差仅0.3897 m³/s；平均误差-0.4893 m³/s，偏差平方占MSE 77.41%；幅度状态UNDER_VARIABLE。
- ID9：L1技能-59.53%，NSE -0.4963；RMSE 10.0452 m³/s，对应观测标准差仅8.2120 m³/s；平均误差-8.9480 m³/s，偏差平方占MSE 79.35%；幅度状态UNDER_VARIABLE。

ID533的冬季观测方差仅为训练期同样日历月份方差的10.80%，ID545为24.89%。小分母放大NSE，但不是“只有分母问题”：533仍有正偏差及过大预测波动；545误差中大部分属于去均值后的形状/幅度失配。ID2/9冬季低估和波动不足；ID383冬季相对技能差却有正NSE，不能混作绝对失败。

训练Q均值/方差、按月气象异常及各季偏差平方占MSE均见P6D_SEASONAL_AND_DRIFT.csv。描述性漂移阈值已标为后验，不是新任务准入门槛。训练Q来自原LamaH，测试Q来自eHYD归档；P6B的2015–2017来源连续性证据只读复用。源版本、日期归属、QC差异仍可能参与均值差异，不能直接称为气候或人工调度变化。

2020-04 Rhine：ID2 T_z=3.435、P_z=-1.557、EXTRAPOLATION_CAUTION；ID6 T_z=3.263、P_z=-1.712、EXTRAPOLATION_CAUTION；ID9 T_z=3.230、P_z=-1.612、EXTRAPOLATION_CAUTION；ID10 T_z=2.979、P_z=-1.733、IN_SUPPORT；ID22 T_z=3.023、P_z=-1.714、EXTRAPOLATION_CAUTION。四站警示由当月T相对训练期4月mu/sd超过3触发；ID10仅2.979，仍IN_SUPPORT。当前P偏低，但均未到|z|>3；前月P也未超阈值。共同警示的算法原因已确认，具体气象事件和径流机制未获独立证明。

## 7. 证据等级与P7决策

P6D_EVIDENCE_GRADE.csv逐条区分CONFIRMED_NUMERICAL、CANDIDATE_EXPLANATION、UNRESOLVED_PHYSICAL_MECHANISM。已证实的是误差位置、标准化特征项及偏差/波动失配；固定季节模板和季节相关记忆响应是候选解释。积雪、水库、取水、地下水、冰川或特定事件不能从这些回归项中识别。

已有证据足以制定小型P7开发假设，但不足以认定通用替代模型。优先在≤2017训练资料的按年份内外验证中检验：①前月P响应是否需要少量预先限定的季节交互；②固定模板的残差均值和幅度失配是否能由合法前期状态解释；③区间过宽是否源于训练期季节校准样本和误差异质性。不得用2018–2020 Q重新标定再称独立测试，也不应并行枚举大量窗口刷分。

未来测试应由独立保管者锁定尚未参与评分、调参或诊断设计的新时期/新流域，先冻结模型、名单、驱动口径和区间规则，再封存预测、后开放Q评分。不能直接把2021以后称为完全盲集：既有P6B/P6C解析器曾转换整份归档；P6D初版独立核验器也在筛年份前转换了归档数值，未用于2021+评分或分析，已保留初版并改成先按年过滤。本轮的正式分析仍仅使用2018–2020。真正盲测宜使用外部保管、尚未取得或接触的新归档时段（例如2024以后，须另核实实际覆盖/许可）；若用已有2021–2023，只能在暴露台账明确后称未评分留出时期，不夸称未接触标签。
